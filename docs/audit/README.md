# 审核报告归档

本目录存放各轮**产品数据审核报告**（由审核 Agent 产出），命名 `审核_<范围>_<YYYY-MM-DD>.md`。
报告模板见仓库根目录 [AGENTS.md](../../AGENTS.md) 第 8 节。

## 用法

- 报告应写明**快照 id**（对应 `data/_locks/` 里的文件），便于追溯审核时的数据状态。
- 审核完成后由审核方 `npm run audit:release -- <快照id>` 解除冻结，再由**用户指派**的一方按报告整改。
- 整改提交时在 commit 信息里引用报告文件名，并同步更新产品的 6 个审核标注字段。

## ⚠️ 关于历史报告中的口径

早期报告（如 `审计_空气净化至洗碗机.md`）采用过**更严格**的规则，例如「严禁用媒体参数补齐」。
该口径已被放宽，**现行规则以 [`skills/appliance-data-curation/SKILL.md`](../../skills/appliance-data-curation/SKILL.md) 为准**：

> 媒体参数**可以作为参考，用于印证**已知信息；但**不能仅凭媒体这一单一来源**给产品定下参数值。

历史报告保留原样不改（它们是当时的审核依据记录），阅读时请注意口径差异。
