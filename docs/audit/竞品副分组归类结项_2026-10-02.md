## 二、依据优先级

分类值按以下顺序取，**每个赋值都把依据写进该产品的 `change_log`**：

1. 第三方规格表的分类字段（太平洋 `产品类型`/`安装方式`/`加热方式`/`类别`，ZOL `产品类型`）
2. 国标型号前缀正则（`KFR-72LW`=柜机、`RUS`/`JSQ`=燃气热水器、`ES`=电热、洗衣机的 `XHQG`/`XQG`/`XQB` 段位）
3. 型号段位编码（西门子洗碗机 `SN`=全嵌 / `SJ`=半嵌 / `SK`=台下；松下 `NP-`/`NW-`=嵌入式）
4. 参数阈值（除湿量分档、电池容量、烟机风力档位）
5. 价格分档（仅用于档位型 facet，如吸尘器旗舰/主流/入门）

**没有依据的保持「未归类」，不猜。** 这符合 `skills/appliance-data-curation/SKILL.md` 的「宁缺勿错」红线。

## 三、证据补抓链路

新增 `scripts/fetch-evidence-2.py`，与已有的 `fetch-missing-specs.py` 配合：

- **按白名单保留字段**：只留分类/参数字段，避开包装清单、颜色、电线长度等噪声
- **并发 4 + 逐条落盘**：抓到 20 条就存一次，中断可续
- **幂等**：已抓到的不重复请求，可反复重跑
- 产出 `data/_cache/facet-evidence/evidence.json`：107 条，含太平洋规格 30 条、ZOL 参数页 19 条

`classify-facets.py` 新增 `load_evidence()` 把这份证据接进分类链路，字段以 `p_`/`z_` 前缀区分来源。

## 四、过程中发现并修正的缺陷

| 缺陷 | 影响 | 修正 |
| --- | --- | --- |
| 咖啡机关键词写「意式」，第三方实际写「**意大利式**」 | 字面匹配落空，14 条有证据却归不了类 | 补齐两种写法，并加注释说明这个坑（`'意式' not in '意大利式'`） |
| 规则里用 `sp.get('产品容量')` 直取值 | evidence 里键名是 `p_产品容量`，全部取空，水壶类 12 条空转 | 抽出 `field()` 统一处理来源前缀回退，全量替换 16 处 |
| `RULES` 里 `water-heater` 仍挂旧版规则 | 新写的 `RUS`/`JSQ` 燃气前缀判断没生效 | 换挂 `rule_waterheater2` |
| 洗碗机型号段位正则锚定行首 | 型号前带中文品牌名「西门子SN67ZX00CC」，匹配不到 | 去掉行首锚定，改搜型号主体 |
| 缺「欧式快热炉」映射 | 格力/松下/飞利浦 5 条油汀被漏掉 | 补映射（第三方对油汀的常见叫法） |
| `bath-heater` 规则按控制方式归类 | 竞品第三方规格普遍不给控制方式，4 条空转 | 改为按取暖功率档位（浴霸核心选购维度） |

## 六、顺带发现的数据错误

**松下 FV-30BQS1 错放在 `heater`（电暖器）品类**，实为浴霸：

- 同站 `bath-heater` 另有 FV-54BET1C / FV-54BDT1C / FV-54BD1C / FV-RB20TS1 / FV-JDBQVL2 五款松下浴霸
- 第三方规格「产品类型」标为「**风暖型浴霸**」，安装方式「集成吊顶式」
- 原 `verify_url` 指向 pconline 的 `heater` 目录亦属错挂

按 `AGENTS.md` 分区流转协议处理：`recall → 按 bath-heater 字段集重建 → publish`，流转日志已记入 `data/_flow/journal.jsonl`。第三方未提供的参数一律「查不到」，核查状态降为「待核验」。

## 七、剩余 28 条未归类

这些是**证据源确实不提供分类信息**的情况，不是抓取失败：

| 品类 | 条数 | 原因 |
| --- | ---: | --- |
| humidifier 加湿器 | 6 | 飞利浦 AC4926/HU4906/AC2726、美的 SZK-U15/U12：第三方规格只有功率与尺寸，无「无雾/超声波」字段。需官方规格页或说明书确认加湿原理 |
| water-purifier 净水器 | 5 | 只有通量（flux），无出水方式与安装方式信息 |
| dehumidifier 除湿机 | 4 | 3 条标为「**工业除湿机**」（德业 DY-6138EB、多乐信 EP-8.8S/DP-12S），而本站 facet 按**家用**除湿量分档，维度不匹配；格力 CF3.8DE 无任何分类字段 |
| dishwasher 洗碗机 | 2 | 松下型号段位未落在已知编码内 |
| coffee-machine 咖啡机 | 2 | 松下 NC-A701 系列：第三方只有「使用方式=自动」，无胶囊/意式区分 |
| robot-vacuum 扫地机器人 | 3 | 石头 G30 Space、大疆 ROMO P2、云鲸逍遥 002：无基站/上下水标注 |
| fan / heater / microwave / refrigerator / water-dispenser / air-conditioner | 各 1 | 单一型号无分类字段 |

**逐条保留「未归类」是正确处理**——界面上的「未归类」分组对用户是诚实的信号，比猜一个值更有用。

要继续推进这 28 条，需要补的方向：品牌官方规格页（飞利浦/美的/松下/西门子官网）、产品说明书 PDF（中国强制随附）、能效标识备案平台。第三方比价站在这类字段上普遍不给。
