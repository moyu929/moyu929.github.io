### 2. F305 重复（审核报告指定项）

结论：**不是同一产品，且其中一条型号标错**。依据小米商城官方 API `api2.order.mi.com/product/view`：

- `fw_5c`（5C）持 `F305`，其规格页 4 项参数与官方逐项吻合 → 型号正确
- `fw_5pro_foam`（5 Pro泡沫版）**不是独立型号**。官方 `product_id=10050233` 的 `buy_option` 显示「5 Pro 泡沫版」是 5 Pro 这同一 `product_id` 下的规格选项；泡沫清洁模组是可单独加装的配件（`product_id=1230807263`，¥399）。该条目参数与 pconline 的 5 Pro 页逐字相同，是从 5 Pro 页复制后把型号栏改成 F305。
- 处理：`fw_5pro_foam` 型号改为 `F302`；**保留独立条目**（它有独立 `product_id=1230808690`、独立售价 ¥2199、主机 6.5kg vs 5 Pro 6.1kg），以 `tags` 标注「泡沫清洁模组套装」区分。共用型号属同机型不同 SKU，不是重复条目。

顺带订正同源参数错误：

| 条目 | 修正 |
| --- | --- |
| `fw_5pro` / `fw_5pro_foam` | 水箱颠倒：原 `净水 700ml / 污水 1000ml` → 官方 `净水 1000ml / 污水 700ml` |
| `fw_4c` | 型号 `4C(D304)` → `D304`；官方回填水箱 740ml / 550ml |
| `fw_3pro` | 型号 `3Pro（D302）` → `D302` |
| `fw_3max` | 型号原写产品名「3 Max」；线索指向 D301 但仅 ZOL 比价库商户标题单源，按宁缺勿错置 `查不到` |
| `fw_5max` | 官方回填水箱 1000ml / 700ml；pconline 该页「1ml/0.7ml」为单位错标，已弃用 |
| `fw_5c` | 官方回填续航 45min |

pconline 全系错误率高（5 MAX 水箱、5 真空度差 10 倍、5 Pro 清水污水互换），本轮以官方 API 为准绳。

### 3. 型号代码核实（审核报告 P0）

核实方法不是只比对型号字符串——把型号页的**制冷量/制热量/风量/噪音与库内数值逐项比对**，只有全等才判确认（太平洋与 ZOL 都有录入错误，只对型号串会误判）。

| 条目 | 修正 | 依据 |
| --- | --- | --- |
| `rice-cooker/rc_ih_4l` | `IHFB01CM` → `IHFB02CM` | 官网 `dianfanbao2/specs` 明确 IHFB01CM=3L、IHFB02CM=4L；`dianfanbao2-4l/specs` 产品型号栏 |
| `air-conditioner/jso_pro_15p` | `KFR-35GW/V1A1` → `KFR-35GW-NA20/V1A1` | 原值缺机系列码且指向另一台老机（互联网空调A，APF5.3/制冷3500）；本条为巨省电Pro 1.5匹（APF5.65/制冷3520/制热5110），ZOL 系列页与太平洋双源 |
| `refrigerator/frig_508_ultra` | `BCD-508WSSGPDIN` → `BCD-508WFSGPDIN` | `WSSGPDIN` 是不存在的字母组合，系 `WFSGPDIN` 次序记反；太平洋规格表三项全等 |
| `washing-machine/wash_dry_102s` | `XQG100MJ102S` → `XHQG100MJ102S` | `XQG` 为滚筒（洗脱一体）前缀，洗烘一体应为 `XHQG`，与 2019 款 `XHQG100MJ01`、2024 款 `XHQG100MJ108` 同类一致 |
| `air-conditioner/gree_2774339` | `72520` → `KFR-72LW/(72520)FNhAc-B1(WIFI)` | 原值仅型号中段数字，补全为完整型号 |
| `air-conditioner/gree_2774279` | `72527` → `KFR-72LW/(72527)FNhAb-B1(WIFI)` | 同上；但完整型号低置信，见下 |

**确认无误**（型号与库内参数逐项吻合）：空调 11 款（含 4 款中央空调、3 款立式柜机）、冰箱 7 款、洗衣机 5 款、创维 `100Q9H`、艾美特 `FA23-SRDI151`。

**撤回我此前的一处误判**：先前标注「3 款立式柜机疑似缺 `KFR-` 前缀待复核」，核实后发现**小米 2022 年后的机型官方零售型号一律不带 `KFR-` 前缀**，太平洋规格表「型号」行与苏宁/京东商品标题均为裸码，库内写法正确，已撤回标注。

**低置信标注**：

| 条目 | 说明 |
| --- | --- |
| `gree_2774279` | 完整型号 `FNhAb-B1(WIFI)` 段无法证实——ZOL 与苏宁对 72527 段收录的均为 `FNhAa-A3`（T雅）；`FNhAb-B1(WIFI)` 段收录的是其他段号（72504/72516/72518/72530/72567）。不排除存在但未被收录，无法证实也无法证伪 |
| `refrigerator/frig_210_three` | `BCD-210WMSDMJ01` 存在且对应（什么值得买百科 + 苏宁双源），但太平洋未收录，非三源印证 |

顺带发现并订正一处参数错误：

- `refrigerator/frig_606_cross` 分仓容积原为 冷藏432/冷冻174（合计恰为 606，无变温区），与「双系统 + 独立三档变温」矛盾。据太平洋规格表订正为 冷藏345/冷冻225/变温36；schema 新增 `var_vol`（变温室）字段，仅有权威来源的两款回填（`frig_508_ultra`=35L、`frig_606_cross`=36L），`frig_508_cross`/`frig_603_cross` 的差额为推算值，按禁止估算原则留空。
