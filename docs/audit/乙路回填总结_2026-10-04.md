- `zol-fetch.py` / `zol-harvest.py` / `zol-lookup.py`：ZOL cookie 过墙抓取三件套（newPm 表格解析、品类 slug 大小写修复）
- 后续丙路/甲路可直接复用。

## 六、方法教训（供后续批次）

1. 小米 API 的系列/集合页会解析到别的产品——商品名+价格双核对才可用
2. pconline 直连时好时坏；ZOL 需 cookie 过墙但有现成工具；ZOL 无「上市时间」行
3. year 只有开售报道弱源可用（双媒体一致 + 报道价与在售价一致）
4. 竞品 official_price 是最大无解缺口：ZOL 未收录的电商专供型号无官方渠道可达
5. 太平洋存在整列错乱（咖啡机重量列）与跨系列复制（尺寸），对可疑值宁缺勿错
