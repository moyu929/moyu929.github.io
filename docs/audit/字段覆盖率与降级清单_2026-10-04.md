# 字段覆盖率与降级清单（2026-10-04）

## 结论先说

`npm run flow:status` 之外，库内还剩 **8668 个空字段**。其中**约 4600 个在现有来源下不可填**，
不是「还没做」，是**做不了**。继续按「补全」的思路投入是浪费。

本文给出逐字段的可达性实测，以及对应的降级处置。

## 可达性实测方法

对每个空字段判定三件事：

1. 该产品的 `verify_url` 是否指向有缓存的第三方规格页（无缓存 = 没有任何数值来源）
2. 即使有缓存，缓存里**是否存在这个字段**（pconline 只发布它收录到的字段）
3. 若存在，值能否通过单位守卫与阈值区间

`scripts/fill-params.py --dry` 就是这个判定的可执行版本。

## 不可填的字段与降级处置

| 字段 | 空值数 | 不可填原因 | 降级处置 |
| --- | --- | --- | --- |
| `year` | 888 | **零来源**。第三方规格页极少给上市时间；官方页不公开 | 从卡片 `grid` 与对比表移除，仅在有值时显示 |
| `size` | 458 | pconline **全部未发布**该字段（458/458） | 同上 |
| `official_price` | 454 | 第三方只给 8 条报价，其余无来源 | 见下方「价格口径」 |
| `miot_model` | 878 | **618 款非小米品牌本就没有这个字段**（小米生态链协议型号只有米家产品有）；260 款小米待精确匹配 | 非小米品牌侧不再视为缺口 |
| `power` | 244 | 155 款无第三方缓存 + 87 款缓存无该字段 | 从卡片 `grid` 移除 |
| `model_code` | 394 | 映射表里根本没有对应源字段，且产品名不足以可靠推出零售型号 | 保留查不到，不再投入 |
| `noise` | 224 | 97 无缓存 + 126 缓存无该字段 | 从卡片 `grid` 移除 |
| `weight` | 170 | 72 无缓存 + 97 缓存无该字段 | 从卡片 `grid` 移除 |

「从卡片 `grid` 移除」不等于删字段：schema 里保留 `key`，有值的产品照常显示，
对比表也照常有这一列 —— 只是**空的时候不再占位显示**。
`ProductCard` 已实现「跳过空值」，所以实际只需保证这些字段不再被当成必填项统计。

## 价格口径（2026-10-04 用户裁决）

**`official_price` 是参考价，不是当前成交价。**

站内价格的作用是**辅助筛选与比较配置**，用户下一步是去电商平台查实时价。
电商价随官方调价、活动折扣、优惠券频繁浮动 —— 统计「当前价格」既做不到也不该做，
追一次快照只会在库里留下一批很快过期的数字。

因此：

- **不为了「保持最新」而覆盖已有价格。** 商城 API 的 `price` 只在该产品**还没有价格**时填入
  （`scripts/fill-mi-official.py` 已强制 `blank(_cur)` 守卫）。
- schema 里 `official_price` 的显示名已从「官方价」改为「参考价」，
  `ref_price` 改为「划线价」（原先两者都叫「参考价」，会撞名）。
- 价格是**比较配置的辅助信息**，不是报价承诺。

## 重新评估的触发条件

出现下列任一情况，上表的「不可填」结论需要重测：

- 接入第二家权威第三方（`data/_sources/source-registry.json` 里 ZOL / 苏宁 / IT168 / 天极网
  目前登记为「能连通」，但**能否解析出规格表尚未验证** —— 这两件事不等价）
- 拿到品牌官方规格页的可抓取入口（2026-10-04 实测：科沃斯 / 添可 / 石头官方站是 SPA，
  商品页正文仅两千余字，参数零命中）
- 拿到上市时间类的公开数据集（`year` 是唯一零来源且需求量大的字段）

## 附录：待指派的两个品类

两个都是**纯小米系**、规模小，但字段缺口集中，适合交给一个人一次做完。

### `dryer-rack`（晾衣机）— 6 款 / 57 空字段

产品：米家智能晾衣机 3 / 2 Pro / Pro / 3C / 双控晾衣机 2 / 隐形晾衣机 单杆

待补字段：`type` `official_price` `load`（承重）`length`（长度）`light`（晾晒容量/灯）
`dry`（烘干）`app` `size` `year`

来源：小米商城 API `mi-store-enumerate.py 晾衣机` → `fill-mi-official.py --cat dryer-rack`。
`load` / `length` / `light` / `dry` 这几项商城可能不给，需从官方规格页或说明书补。

### `hair-clipper`（理发器）— 3 款 / 39 空字段

产品：米家理发器 2 / 理发器 2 套装版 / 理发器 儿童版

待补字段：`type` `official_price` `runtime`（续航）`blades`（刀头）`waterproof`（防水）
`display` `power` `size` `year`

注意 **套装版**与单机版的区别：套装含配件，`verify_url` 若指向套装 SKU，
`official_price` 会取到套装价而非主机价（`fill-mi-official.py` 已有 `ACCESSORY_RE`
守卫能挡一部分，但「理发器 2 套装版」这种命名挡不住，需人工确认）。

### 执行要点

1. 开独立 worktree（AGENTS.md §3.6）
2. `python scripts/mi-store-enumerate.py 晾衣机 理发器` 先定位 `product_id`
3. `python scripts/fill-mi-official.py --cat dryer-rack,hair-clipper` 回填
4. `flow:submit` → `flow:claim` → `flow:publish`
5. `official_price` 按**参考价**口径录入，**不追实时价**
