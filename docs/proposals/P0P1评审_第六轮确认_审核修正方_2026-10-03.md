## 1. 对第 1 条理由（规则恒真）的核实

**成立，且这是我方案里的实质缺陷。**

我核实了 `scripts/fill-model-codes.py` 的 `pick()`：

```python
def pick(name, brand):
    c = candidates(name, brand)      # candidates 用 MODEL_WITH_PAREN.finditer(nm)
    ...
    return c[0]
```

`candidates()` 是对**产品名字符串本身**做正则匹配，返回的每个候选必然是 `name` 的子串。

所以「`source === 'name'` 时检查型号是否出现在产品名里」——**在数学上不可能失败**。

我提这条规则时的意图是「抓提取时截错了」，但那个 bug 发生在 `candidates()` 内部
（正则边界、括号配平、后缀吞并），而 `pick()` 无论返回哪个候选都满足「是 name 的子串」。

**规则抓不到我想抓的东西。** 这不是优先级问题，是逻辑无效。你说得对。
